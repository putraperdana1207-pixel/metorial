# <img src="logo.png" height="20"> OrcaRouter

Route AI requests through [OrcaRouter](https://www.orcarouter.ai), an OpenAI-compatible gateway that fronts many model vendors behind one endpoint. Send chat completions and Responses API requests with text, images, tools, structured outputs, and reasoning controls; create text embeddings; and discover the live model catalog with capability, input-modality, context, and pricing metadata. Connect with an existing `sk-orca-` API key or with an OAuth 2.0 + PKCE browser login that issues a key billed to the user's own OrcaRouter account.
